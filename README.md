# Blender 做中學｜讀者實作配套

作者：Happy eBook Authors

出版：Happy eBook

本倉庫只提供《Blender 做中學：從第一個模型到完整作品》的範例、實作程式、配套使用說明與官方參考連結，不提供章節內文、電子書、編輯紀錄或含書稿的壓縮檔。

## 下載與開始

1. 點選本頁上方 **Code → Download ZIP**，或使用[直接下載](https://github.com/t945935/blender-hands-on-book/archive/refs/heads/main.zip)。不需要安裝 Git，也不需要登入帳號。
2. 完整解壓，不要直接在 ZIP 中開啟 Blender 檔案。
3. 在 Blender 開啟 `examples/reading-corner/chapter01-start.blend`。
4. 立即另存到自己的練習資料夾，再依書中說明操作。不要覆寫起始檔。

目前提供第1章桌面閱讀角落配套，以及[第2章場景整理完成參考](examples/scene-organization/README.md)；其他章配套尚未發布。已實測環境為 Windows Blender 5.2.2 LTS，不保證所有版本／平台結果相同。
